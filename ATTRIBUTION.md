# Attribution and contribution boundaries

## User-confirmed historical contribution

- Early lessons used a teacher-provided framework; detailed implementation was developed by the author together with classmates.
- Later real-data exercises were primarily implemented by the author.
- Some tasks were group work, with the author serving as main contributor/responsible member.
- A precise contribution percentage for every historical file is not available.

These statements describe the historical coursework. They do not establish sole authorship of all framework/helper code.

## Public implementation in this candidate

The functions, tests, synthetic generator, plots and documentation in this candidate were newly prepared with substantial AI assistance in October 2026 to reconstruct selected coursework themes. They are clearly separated from the historical scripts and are not presented as the author's original course-time code.

The private audit retains file hashes and a map to the twelve historical sources. No original teacher instruction documents, third-party source trees, raw clinical tables, unreviewed helper bodies, RData/RDS or private reports were copied into the public candidate.

Standard statistical implementations come from R's stats package and the external survival package. Those components are not vendored. This is not a new PCA or survival-analysis method.

## Unverified or excluded

The original comprehensive workflow, enrichment, nomogram, ROC and fixed-count volcano figures have not been numerically reproduced. Their code presence is not a validated result. Overlapping comprehensive scripts count as one coursework workflow.

There is no project-wide license selection yet. Excluded course and peer materials have not been relicensed by this candidate.
